# Decision log

This is the single decision log for the complete system and all components.
Record unresolved matters in [Open questions](open-questions.md).

Record each decision or baseline change here. Do not delete rows. Mark a replaced row as `Superseded`.

| ID   | Date       | Decision                                                                                                                                                                                                                                                             |
| ---- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-01 | 2026-10-21 | Core split: Core 0 executes hard real-time control (PIO, ADC, PID, actuators); Core 1 executes networking, web server, and telemetry.                                                                                                                                |
| D-02 | 2026-10-21 | AC synchronization: lock control loop to mains frequency (50/60 Hz) triggered by the falling edge of the zero-cross optocoupler input.                                                                                                                               |
| D-03 | 2026-10-21 | Actuator switching isolation: pump triac uses random-phase MOC mid-half-wave; boiler heater uses zero-cross MOC latched 2 ms after the zero-cross edge.                                                                                                              |
| D-04 | 2026-10-21 | Hardware heater fail-safe: heater PIO state machine uses `pull noblock` where empty FIFO reads 0 (OFF). If control task stalls, heater turns off without software intervention.                                                                                      |
| D-05 | 2026-10-21 | Superseded by D-13 and D-14: Dual network interfaces: Port 80 serves interactive HTTP/JSON web dashboard; port 8080 streams raw postcard binary frames and receives newline-delimited JSON commands.                                                                  |
| D-06 | 2026-10-21 | Safe-boot fallback: holding the Flush button during boot forces Wi-Fi Access Point mode for credential recovery.                                                                                                                                                   |
| D-08 | 2026-10-21 | Shared analog nets: GP26 and GP27 share physical PCB nets with GP40 (A0) and GP41 (A1). Firmware configures GP26/GP27 as high-impedance inputs (`Pull::None`).                                                                                                       |
| D-09 | 2026-10-21 | Dual-PID architecture: separate PID controllers for thermal regulation (`temp_pid` at 5 Hz with flow feed-forward) and pump modulation (`pump_pid` at 50 Hz). Profiles use 2D steps with simultaneous pressure and flow targets, governed by the binding constraint. |
| D-10 | 2026-10-21 | Resolved open questions: 3 min maximum continuous heating cut-off (REQ-14), 145 °C steam target safety ceiling (REQ-15), equal to the REQ-03 heater cut-off, and a maximum of 10 stored brew profiles (REQ-16).                                                        |
| D-11 | 2026-11-21 | Shared `no_std` crate `proto/` (`oximite-proto`) owns domain models, JSON uplink command schemas (`ApiCommand`), and Port 8080 Postcard wire codecs across `firmware/`, `host-tests/`, and `control/`.                                                                |
| D-12 | 2026-11-21 | Pure-logic versus hardware-task split in `firmware/src/`: 11 pure `no_std` modules run natively under `host-tests/` (unit, fuzz, and closed-loop simulation), replacing the deleted Python `tests/` suite.                                                             |
| D-13 | 2026-11-21 | Superseded by D-18: Port 8080 protocol v3 (`magic = 0x4D49_584F` `"OXIM"`, `proto_ver = 3`): downlink uses `[len: u16 LE][postcard DeviceMsg]` typed envelopes; uplink keeps newline-delimited JSON (`ApiCommand`) compatible with `POST /api/cmd`, extended with `req_id`, read queries, and stream divider control. |
| D-14 | 2026-11-21 | Port 80 web UI (`firmware/html/index.html`) is a lightweight, zero-CDN, graph-free control and Wi-Fi setup page. `GET /api/settings` exposes `PublicSettings` (`wifi.ssid` and `wifi.has_password`) so stored Wi-Fi passwords never cross the network.             |
| D-15 | 2026-11-21 | Native desktop companion app (`control/` / `oximite-control`, `eframe`/`egui`) connects directly by IP or hostname over TCP port 8080 (no UDP LAN discovery) for synchronized 3-panel live graphing, PID tuning, profile editing, bench sweeps, shot replay/comparison, and event logging. |
| D-16 | 2026-11-21 | Mid-shot persistence deferral and coalesced flash storage: `Ambient::RamAndFlash` commands (`SaveMachine`, `SavePids`, `SaveWifi`, `SaveProfile`, `DeleteProfile`) defer both RAM and flash updates until idle (`!state.is_busy()`), coalescing per section (`DeferredWrites`) and flushing dirty keys via `sequential-storage 8.0.2`. `SetSessionTemp` (`Ambient::RamOnly`) applies immediately to RAM. |
| D-17 | 2026-11-21 | Wi-Fi reconnect hardening adapted from `lite` (`D-80`, `D-81`): STA supervisor monitors both `wait_link_down()` and `wait_config_down()`, runs a self-arming ICMP gateway reachability probe (`GatewayProbeTracker`, skipped during recent inbound LAN activity), tears down active Port 80/8080 sockets via `wait_network_down()` and TCP keep-alive/timeout (15 s / 45 s), calls bounded `leave()` before every retry, and seeds `embassy-net` from RP2350 OTP chip ID XOR `RoscRng`. |
| D-18 | 2026-11-23 | Simplify the protocol. Port 80 handles all commands and queries and replies directly. Port 8080 is one-way Postcard telemetry with only `Tick(WireTick)` and `Event`. There is no Hello, no `req_id`, no stream control and no uplink. `WireTick` uses fixed-point integers to stay small. The two ports stay independent. Supersedes D-13. |
| D-19 | 2026-11-23 | Four buttons share one ADC pin (GP42) through a resistor ladder, so the front panel needs four wires. Main PCB: 10k pull-up to 3V3. Panel: always-on Rref 100k, and per button to GND: Power 42.2k, Steam 13.7k, Flush 5.76k, Brew 1.78k. One button at a time. Open and short readings are faults and never issue a command. Panel limit 60 °C. Replaces GP5..GP8 inputs and `debounce.rs`. Safe-boot (D-06) reads the ladder. |
